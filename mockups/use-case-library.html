One core pattern, five adaptations. The diagram barely changes between verticals; the words change completely — so only the words get regenerated. That's why the pattern is use-case-first and the vertical is a layer on top, not the other way round.

Problem — as a law firm experiences it

Firms take in documents from outside counsel, clients and opposing parties all day, through portals and shared mailboxes nobody in IT controls. The files are the business, so blocking them isn't an option, and the senders can't be vetted. One weaponised document in a discovery set reaches a partner's workstation with full access to client matter files.

Solution value

Can't refuse files from unvetted senders
Every inbound document is scanned by multiple engines before it reaches a workstation, so the firm keeps accepting files without trusting their source.
Detection alone misses targeted documents
Deep CDR rebuilds each file rather than judging it, so a macro or embedded object is removed whether or not any engine has seen it before.
Client confidentiality obligations
Files are processed inside the firm's own environment — nothing is sent to a cloud service for analysis.
